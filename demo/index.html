Load Get Done in Chrome or Edge

  1. Open chrome://extensions.
  2. Turn on Developer mode.
  3. Choose Load unpacked and select the extension folder in this project.
  4. Pin Get Done. Paste one image link per question, then open the real homework.

On Canvas, Pearson, Edfinity, and the other sites it recognizes, the panel opens on the right. Drag the top bar to move it, pull a corner to resize, or dock it left. Each time the question counter moves forward, the next picture flashes.
